# Customer Retail Sales Behavior Analysis

📊 End-to-end retail analytics project focused on understanding customer purchasing behavior, spending patterns, customer segmentation, and subscription trends using Python, MySQL, and Power BI.

## Project Files

* `customer_shopping_behavior.csv` – Raw dataset
* `Customer_shopping_behaviour_analysis.ipynb` – Data cleaning, preprocessing, and exploratory analysis using Python
* `customer_behavior_SQL_queries.sql` – Business analysis queries written in MySQL
* `Customer_behaviour_dashboard.pbix` – Interactive Power BI dashboard
* `Customer Shopping Behaviour Analysis.pdf` – Project documentation and findings

## Tools & Technologies

* Python (Pandas, NumPy)
* MySQL
* Power BI
* Jupyter Notebook
* Git & GitHub

## Key Business Analyses

* Revenue by Gender
* Revenue by Age Group
* Subscriber vs Non-Subscriber Spending
* Customer Segmentation (New, Returning, Loyal)
* Top-Rated Products
* Discount Impact Analysis
* Shipping Type Comparison
* Repeat Purchase Behavior
